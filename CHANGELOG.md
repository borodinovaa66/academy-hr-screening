# Changelog

## v0.1.0-pilot

- Candidate questionnaire flow with one question per screen.
- Welcome screen with Sasha character and consent checkboxes.
- 20-question SMM manager screening methodology.
- Automatic scoring, statuses, stop factors, strengths, risks, HR recommendation.
- Admin dashboard and candidate profile drawer.
- SQLite storage for submissions, users, sessions, and methodology config.
- Admin authentication with password hash and HttpOnly cookie.
- Editable questionnaire methodology in admin area.
- Public legal pages:
  - `/privacy`
  - `/personal-data-consent`
- Consent version capture:
  - `privacy_v2`
  - `personal_data_consent_v2`
- HTTPS domain: `https://hr.academy-management.ru`.
- Favicon and visual assets for Sasha.
