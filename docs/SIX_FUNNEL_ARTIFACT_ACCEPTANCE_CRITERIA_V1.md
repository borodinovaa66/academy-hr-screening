# Минимальные критерии принятия шести материалов воронки v1

Дата: 15 сентября 2026 года  
Карточка координации: `HR-XFER-20260915-01`  
Статус документа: результат методолога на проверке; наличие этого текста не означает утверждение материалов конкретной вакансии  
Область: профиль должности, текст вакансии HeadHunter, анкета, тестовое задание, первичное интервью рекрутера и финальное интервью ЛПР

## 1. Назначение

Документ задаёт минимальные проверяемые условия, после которых человек может признать один из шести материалов готовым для конкретной вакансии.

Он применяется вместе с:

- [методологическим стандартом v2](EVIDENCE_BASED_HIRING_STANDARD_V2.md);
- [шаблоном доказательного пакета роли v2](ROLE_PACKAGE_TEMPLATE_V2.md).

Материал считается принятым только при одновременном выполнении трёх условий:

1. каждый обязательный критерий получил отметку `ПРОЙДЕНО`;
2. в карточке материала зафиксированы ФИО или роль проверяющего, дата, версия и комментарий;
3. уполномоченный человек явно поставил статус `УТВЕРЖДЁН`.

Автоматическая проверка и оценка ИИ могут готовить черновик и находить пробелы, но не заменяют человеческое утверждение.

## 2. Единая форма проверки

| Поле | Допустимое значение |
| --- | --- |
| Вакансия и код | Непустое значение из справочника ролей |
| Версия материала | Номер или дата версии |
| Связанная версия профиля | Номер утверждённого профиля |
| Проверяющий | ФИО или однозначная роль |
| Дата проверки | Дата и время |
| Результат каждого критерия | `ПРОЙДЕНО` / `НЕ ПРОЙДЕНО` / `НЕ ПРИМЕНИМО` с обоснованием |
| Итог | `УТВЕРЖДЁН` / `НА ДОРАБОТКУ` |
| Комментарий | Что подтверждено или что исправить |

`НЕ ПРИМЕНИМО` разрешено только с письменным объяснением, почему критерий объективно не относится к этой роли. Оно не используется вместо отсутствующих данных.

## 3. Профиль должности

**Кто принимает:** ЛПР. Методолог или HR проверяет комплектность, но не утверждает за ЛПР бизнес-результат роли.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| П-01 | Указаны код роли, версия, ЛПР, HR-владелец и причина открытия | Все пять полей заполнены; нет `TBD` |
| П-02 | Роль связана с конкретным местом в оргструктуре | Указаны руководитель, направление и границы ответственности; нет дублирования соседней роли без объяснения |
| П-03 | Сформулирован один ценный конечный результат | Формулировка описывает наблюдаемый результат для бизнеса или клиента, а не перечень действий |
| П-04 | Заданы 3–5 измеримых результатов на 6–12 месяцев | У каждого результата есть срок, стандарт или метрика и источник проверки |
| П-05 | Описаны 5–8 критических рабочих задач | Каждая задача необходима хотя бы для одного результата П-04 |
| П-06 | Выбраны 5–7 ключевых компетенций | Каждая компетенция связана минимум с одной задачей П-05 и описана через наблюдаемое поведение |
| П-07 | Для каждой компетенции есть якоря уровней 1, 3 и 5 | По тексту якорей два проверяющих могут отличить слабое, минимально рабочее и сильное проявление |
| П-08 | Обязательные и желательные требования разделены | Для каждого обязательного требования записано, почему без него нельзя выполнить работу на входе |
| П-09 | Стоп-факторы связаны только с работой | Нет пола, возраста, семейного положения, внешности, личных вкусов и других признаков, не связанных с деловыми качествами |
| П-10 | Составлена карта доказательств | Каждая критическая компетенция проверяется минимум двумя независимыми источниками; указан этап проверки |
| П-11 | Условия и ограничения роли подтверждены | Формат, график, география, подчинение и доступный диапазон дохода согласованы ответственным владельцем |
| П-12 | ЛПР подтвердил профиль до подготовки финальной воронки | Есть явная запись `УТВЕРЖДЁН`, версия, дата и проверяющий |

**Не принимать, если:** профиль состоит преимущественно из общих качеств; результаты нельзя измерить; обязательные требования не обоснованы; карта доказательств отсутствует; ЛПР не подтвердил версию.

## 4. Текст вакансии HeadHunter

**Кто принимает:** HR-владелец вакансии. ЛПР подтверждает факты о роли, условиях и доходе.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| Х-01 | Текст создан из утверждённой версии профиля | В метаданных указана версия профиля; обязанности и требования прослеживаются до неё |
| Х-02 | Заголовок содержит одну понятную должность | В заголовке нет слогана, зарплаты, графика, нескольких ролей или необъяснимой аббревиатуры |
| Х-03 | Вступление за 2–4 строки объясняет компанию, причину найма и влияние роли | Все три элемента присутствуют и подтверждены фактами |
| Х-04 | Указаны 4–7 конкретных обязанностей | Каждый пункт описывает рабочую задачу или результат; нет неопределённого «выполнять поручения» как основной обязанности |
| Х-05 | Указаны 4–6 обязательных требований | Они совпадают с обязательными требованиями профиля; желательные признаки вынесены отдельно |
| Х-06 | Дано реалистичное представление о работе | Есть конкретный блок о сложности, ограничениях или о том, кому работа не подойдёт; он не содержит дискриминации |
| Х-07 | Условия полны и проверены | Указаны формат, график, оформление, география, структура дохода и иные существенные условия; владелец подтвердил достоверность |
| Х-08 | Этапы отбора прозрачны | Названы этапы этой вакансии и ориентировочные затраты времени кандидата |
| Х-09 | Призыв ведёт к отклику внутри hh.ru | В описании нет внешней ссылки на анкету, контактов и текста согласия на обработку персональных данных |
| Х-10 | Текст проходит правовую и модерационную проверку | Нет прямых или косвенных ограничений по признакам, не связанным с работой; название, обязанности и требования согласованы между собой |
| Х-11 | Текст читается по диагонали | Независимый читатель за 30 секунд правильно называет роль, основные задачи, требования, условия и следующий шаг |
| Х-12 | HR и ЛПР подтвердили финальную версию | HR ставит `УТВЕРЖДЁН`; подтверждение ЛПР по фактам приложено или зафиксировано в истории |

**Не принимать, если:** текст «продаёт» общими обещаниями; скрывает доход или существенные ограничения без подтверждённой причины; содержит внешнюю ссылку; условия отличаются от профиля; отсутствует человеческая проверка фактов.

## 5. Анкета первичного отбора

**Кто принимает:** методолог или HR-владелец методики. ЛПР подтверждает только профессиональную уместность вопросов и проходных минимумов.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| А-01 | Каждый вопрос связан с профилем | У вопроса указаны проверяемая компетенция, требование или условие и ссылка на соответствующий пункт профиля |
| А-02 | Анкета не повторяет резюме без необходимости | Для каждого повторяющего вопроса записано, зачем нужен отдельный структурированный ответ |
| А-03 | Объём соответствует первичному этапу | Содержит 3–6 объективных вопросов, не более одного вопроса на подтверждающий кейс или артефакт и 1–2 ситуационных вопроса |
| А-04 | Время прохождения проверено | Минимум два человека прошли анкету; медианное или оба наблюдаемых значения не превышают 10 минут, целевое — 5–8 минут |
| А-05 | Для каждого вопроса определено решение | Указан тип: `допуск`, `доказательный балл`, `флаг для проверки` или `без оценки` |
| А-06 | Проходные вопросы действительно критичны | Для каждого автоматического ворота ЛПР письменно подтвердил, что отсутствие условия делает работу невозможной на входе |
| А-07 | Открытые ответы оцениваются по элементам решения | Рубрика проверяет действия, логику, результат и риски; совпадение ключевых слов само по себе не даёт проходной балл |
| А-08 | Ситуационные вопросы имеют якоря 1, 3 и 5 | Есть примеры слабого, минимально рабочего и сильного ответа без единственного «секретного слова» |
| А-09 | Нет запрещённых и лишних персональных вопросов | Нет вопросов о защищённых признаках, здоровье и личной жизни без отдельного законного и рабочего основания |
| А-10 | Кандидату понятны цель, время и работа автоматизации | Перед стартом показаны длительность, использование данных, роль ИИ и способ запросить человеческий пересмотр |
| А-11 | Отрицательное решение не остаётся исключительно автоматическим | В маршруте указан человек, который подтверждает отказ или рассматривает возражение |
| А-12 | Анкета испытана целиком | Проверены успешное заполнение, обязательные поля, пустые и ошибочные ответы, сохранение версии и итоговый маршрут |

**Не принимать, если:** есть баллы за ключевые слова; суммарный балл может компенсировать провал критического требования; анкета не проходилась целиком; нет понятного владельца ручного пересмотра.

## 6. Тестовое задание

**Кто принимает:** ЛПР подтверждает профессиональную близость реальной работе; методолог или HR подтверждает справедливость условий и рубрики.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| Т-01 | Задание воспроизводит критическую задачу роли | Указана конкретная задача профиля и компетенции, которые она проверяет |
| Т-02 | Задание ограничено по времени | Заявлено 45–90 минут; до 2 часов допускается только с обоснованием для сложной роли |
| Т-03 | Входные данные безопасны и одинаковы | Используются синтетические или обезличенные данные; кандидаты одной версии получают одинаковый бриф |
| Т-04 | Задание не создаёт бесплатную работу для компании | Результат нельзя без существенной переработки использовать как реальный коммерческий продукт; это подтверждено ЛПР |
| Т-05 | Инструкция самодостаточна | Указаны контекст, входные данные, результат, формат, срок, ограничение времени и что делать не нужно |
| Т-06 | Правила использования ИИ и других инструментов явны | Кандидат заранее знает, что разрешено, что нужно раскрыть и что будет оцениваться как его собственное решение |
| Т-07 | Есть 4–6 критериев оценки | Каждый критерий связан с профилем; декоративное оформление не компенсирует профессиональную ошибку |
| Т-08 | У каждого критерия есть якоря 1, 3 и 5 | Оценщик может поставить балл по наблюдаемым признакам результата |
| Т-09 | Критические критерии имеют отдельный минимум | Указано, какой провал нельзя компенсировать высоким средним баллом |
| Т-10 | Процесс оценки воспроизводим | Два оценщика на пробном ответе дают баллы без расхождения более чем на один пункт по большинству критериев; большее расхождение разобрано и рубрика уточнена |
| Т-11 | Проверены сильный и слабый контрольные ответы | Для каждого есть ожидаемый профиль баллов и объяснение; это не передаётся кандидатам как шаблон ответа |
| Т-12 | Финальная версия утверждена двумя ролями | ЛПР и методолог/HR явно зафиксировали версию, дату и `УТВЕРЖДЁН` |

**Не принимать, если:** задание слишком объёмно; использует текущую бизнес-задачу компании; нет ограничений на время; рубрика оценивает общее впечатление; отсутствует отдельный минимум по критическим ошибкам.

## 7. Первичное интервью рекрутера

**Кто принимает:** методолог или HR-владелец процесса. ЛПР подтверждает профессиональные критерии, которые передаются на финальный этап.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| Р-01 | Цель этапа отделена от финального интервью | В сценарии явно указано: карьерные факты, мотивация, сквозные компетенции, условия и противоречия; глубокая профессиональная оценка ЛПР не дублируется |
| Р-02 | Длительность ограничена 30–40 минутами | Сумма времени блоков не превышает 40 минут без отдельного обоснования |
| Р-03 | Есть одинаковое ядро вопросов | Для всех кандидатов одной версии определены одни и те же вопросы и порядок |
| Р-04 | Каждый оценочный вопрос связан с профилем | Указаны компетенция или риск и источник ожидаемого доказательства |
| Р-05 | Используются вопросы о прошлом поведении | Минимум по одному вопросу на результат, ошибку/вывод, ответственность и рабочую коммуникацию |
| Р-06 | Есть стандартные уточнения | Интервьюер извлекает ситуацию, задачу, личные действия, результат, вывод и возможное подтверждение, не подсказывая ответ |
| Р-07 | Проверяются противоречия материалов кандидата | До интервью формируется отдельный список расхождений резюме, анкеты и тестового; сценарий содержит место для результата проверки |
| Р-08 | Для оцениваемых компетенций есть якоря 1, 3 и 5 | Балл выводится из зафиксированных фактов, а не из «понравился / не понравился» |
| Р-09 | Интервьюер оценивает независимо | Сначала фиксируются заметки и человеческие баллы, затем показывается оценка ИИ или другого оценщика |
| Р-10 | Нет нерабочих и дискриминационных вопросов | В сценарии отсутствуют вопросы о личной жизни и защищённых признаках без законного рабочего основания |
| Р-11 | Выход этапа стандартизирован | Есть сильные доказательства, риски, непройденные минимумы, противоречия, уровень уверенности и вопросы для ЛПР |
| Р-12 | Сценарий прошёл пробное интервью | Один полный прогон уложился во время; проверяющий смог заполнить выходную форму без свободного додумывания критериев |

**Не принимать, если:** интервью представляет собой свободную беседу; вопросы различаются между кандидатами без причины; оценка выставляется после просмотра оценки ИИ; результатом служит только общий балл.

## 8. Финальное интервью ЛПР

**Кто принимает:** ЛПР. Методолог проверяет структуру и воспроизводимость, но не утверждает профессиональное содержание за ЛПР.

| № | Обязательный критерий | Как проверить |
| --- | --- | --- |
| Л-01 | Определены правила допуска к этапу | Кандидат приходит только после проверки обязательных ворот, тестового и первичного интервью либо по документированному исключению ЛПР |
| Л-02 | Длительность ограничена 45–60 минутами | Сумма времени блоков не превышает 60 минут без отдельного обоснования |
| Л-03 | Сценарий проверяет 3–4 критические задачи роли | Каждая задача взята из утверждённого профиля и имеет отдельный вопрос или кейс |
| Л-04 | Разбор тестового обязателен | Есть вопросы о логике, допущениях, приоритетах, ошибках и альтернативном решении кандидата |
| Л-05 | Проверяются пограничные и противоречивые сигналы | До интервью приложен персональный список фактов для проверки; стандартное ядро при этом не меняется |
| Л-06 | Есть одинаковое ядро вопросов и кейсов | Финалисты одной версии проходят сопоставимый набор; различающиеся уточнения помечаются как проверка конкретного риска |
| Л-07 | Для каждой критической компетенции есть якоря 1, 3 и 5 | ЛПР оценивает наблюдаемое качество решения, а не харизму или похожесть на себя |
| Л-08 | Реалистичные ограничения роли обсуждаются прямо | Кандидату сообщаются фактические ресурсы, полномочия, сложные стороны работы и ожидания руководителя |
| Л-09 | Баллы фиксируются до общей дискуссии и оценки ИИ | История содержит время человеческой оценки и последующего просмотра других оценок |
| Л-10 | Критический провал не скрывается средним баллом | Итог отдельно показывает каждый непройденный минимум и возможное документированное исключение |
| Л-11 | Субъективная часть отделена от доказательной | ЛПР может записать личный риск или предпочтение, но не выдаёт его за подтверждённую компетенцию |
| Л-12 | Итоговое решение объяснено фактами | Выход содержит решение, 3–5 ключевых доказательств, риски, уровень уверенности и при необходимости точечную дополнительную проверку |
| Л-13 | Сценарий прошёл пробный прогон | ЛПР или заменяющий эксперт уложился во время и смог применить шкалы к одному контрольному кейсу |
| Л-14 | ЛПР утвердил версию | Зафиксированы версия, дата, ЛПР и статус `УТВЕРЖДЁН` |

**Не принимать, если:** ЛПР видит только средний балл; интервью не связано с задачами роли; итог сформулирован как «есть/нет химии»; неизвестно, какое доказательство привело к решению.

## 9. Итоговая матрица готовности вакансии
