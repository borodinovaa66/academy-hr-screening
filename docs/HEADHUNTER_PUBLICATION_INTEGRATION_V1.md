# Размещение вакансий на HeadHunter v1

## 1. Цель

Нужно, чтобы платформа подбора могла готовить вакансию для публикации на HeadHunter и, по возможности, автоматически публиковать или обновлять ее через программный интерфейс HeadHunter.

Главная логика:

1. Вакансия создается у нас в платформе.
2. Платформа собирает публичный текст вакансии.
3. В тексте вакансии размещается ссылка на анкету на нашей платформе.
4. Кандидат переходит по ссылке и проходит нашу воронку.

## 2. Можно ли размещать вакансии автоматически

Предварительный вывод: да, технически это возможно, но только при выполнении условий HeadHunter.

Что нужно:

- учетная запись работодателя на HeadHunter;
- зарегистрированное приложение для работы с программным интерфейсом;
- авторизация работодателя;
- оплаченные публикации вакансий;
- соблюдение правил модерации вакансий;
- согласование формата внешней ссылки на нашу платформу.

HeadHunter в своих материалах указывает, что через программный интерфейс можно публиковать и обновлять вакансии, но сами публикации приобретаются так же, как при работе через сайт.

## 3. Важное ограничение по ссылке на нашу платформу

Критичный вопрос: разрешит ли HeadHunter размещать в тексте вакансии внешнюю ссылку или кнопку, ведущую на нашу платформу.

Это нужно согласовать с менеджером HeadHunter до разработки интеграции.

Если внешняя ссылка разрешена:

- размещаем ссылку в тексте вакансии;
- добавляем понятный призыв: "Пройдите короткую анкету на нашей платформе";
- передаем в ссылке код вакансии и источник.

Если внешняя ссылка запрещена или режется модерацией:

- используем HeadHunter как источник откликов;
- забираем отклики из HeadHunter;
- отправляем кандидату ссылку на нашу платформу через сообщение или письмо;
- в карточке кандидата храним источник `HeadHunter`.

## 4. Какие данные нужны для публикации

Из карточки вакансии платформа должна собрать:

- название вакансии;
- город или удаленный формат;
- зарплатную вилку;
- занятость;
- график;
- опыт;
- обязанности;
- требования;
- условия;
- преимущества;
- описание компании;
- ссылку на анкету;
- контактного ответственного;
- внутренний код вакансии.

## 5. Текст вакансии для HeadHunter

Для каждой вакансии нужен отдельный шаблон текста:

1. Короткое описание компании.
2. Зачем открыта роль.
3. Что предстоит делать.
4. Какой опыт нужен.
5. Что будет преимуществом.
6. Какие условия предлагаем.
7. Как проходит отбор.
8. Ссылка на короткую анкету.

Важное правило: текст вакансии должен продавать роль, но не обещать лишнего. Слабый текст даст плохой поток кандидатов, даже если платформа отбора работает хорошо.

## 6. Данные для ссылки на нашу платформу

Ссылка должна содержать:

- код вакансии;
- источник;
- канал или кампания;
- при необходимости - код конкретной публикации.

Пример:

`https://hr.academy-management.ru/v/smm-specialist?source=headhunter`

В интерфейсе это называется не технически, а просто: "Ссылка на анкету кандидата".

## 7. Что нужно проверить с HeadHunter

Список вопросов менеджеру HeadHunter:

1. Можно ли в тексте вакансии размещать внешнюю ссылку на анкету работодателя?
2. Можно ли оформить это как кнопку или только как текстовую ссылку?
3. Не будет ли такая ссылка причиной отклонения вакансии на модерации?
4. Можно ли публиковать и обновлять вакансии через программный интерфейс на нашем тарифе?
5. Какие действия через программный интерфейс платные?
6. Можно ли получать отклики по опубликованным вакансиям?
7. Какие ограничения есть по обработке персональных данных кандидатов во внешней системе?
8. Какие поля вакансии обязательны для автоматической публикации?

## 8. Минимальная рабочая версия интеграции

Не нужно начинать с полной автоматической публикации.

Первый этап:

1. Платформа генерирует готовый текст вакансии.
2. Платформа генерирует ссылку на анкету.
3. Специалист по подбору вручную публикует вакансию на HeadHunter.
4. Кандидат переходит по ссылке на нашу платформу.
5. В карточке кандидата фиксируется источник `HeadHunter`.

Второй этап:

1. Подключаем программный интерфейс HeadHunter.
2. Публикуем черновик вакансии из нашей платформы.
3. Обновляем вакансию из нашей платформы.
4. Получаем статус публикации.
5. Связываем опубликованную вакансию HeadHunter с нашей вакансией.

## 9. Критерии готовности

Интеграция считается готовой, если:

- вакансия создается у нас один раз;
- текст для HeadHunter формируется автоматически;
- ссылка на нашу анкету работает;
- кандидат из HeadHunter попадает в правильную воронку;
- источник кандидата сохраняется;
- специалист по подбору видит кандидата в нужной вакансии;
- есть понятный запасной сценарий, если HeadHunter не разрешит внешнюю ссылку.
