# Расширенная воронка подбора v1

## 1. Что меняем

Текущая платформа закрывает первичный отбор: анкета, автоматическая оценка, тестовое задание, карточка кандидата.

Следующая версия должна закрывать процесс до решения о предложении работы:

1. публикация вакансии;
2. переход кандидата на нашу платформу;
3. первичная анкета;
4. тестовое задание;
5. интервью со специалистом по подбору;
6. расшифровка интервью;
7. независимая оценка интервью искусственным интеллектом;
8. независимая оценка интервью специалистом по подбору;
9. интервью с руководителем-заказчиком;
10. расшифровка второго интервью;
11. независимая оценка второго интервью искусственным интеллектом;
12. независимая оценка руководителем;
13. итоговая оценка по всей воронке;
14. решение руководителя о предложении работы;
15. сборка и отправка предложения работы;
16. отметка "предложение принято";
17. запуск следующего процесса - адаптация нового сотрудника.

Адаптацию нового сотрудника в эту версию не включаем. Только ставим точку запуска.

## 2. Этапы воронки

| Этап | Кто отвечает | Что делает платформа | Решение |
| --- | --- | --- | --- |
| 1. Карточка вакансии | Руководитель + специалист по подбору | Хранит требования, грейд, зарплатную вилку, этапы | Вакансия готова к публикации |
| 2. Публикация | Специалист по подбору | Готовит текст для HeadHunter и ссылку на нашу анкету | Вакансия опубликована |
| 3. Переход кандидата | Кандидат | Принимает кандидата по ссылке из вакансии | Кандидат начал воронку |
| 4. Первичная анкета | Кандидат | Собирает ответы, резюме, контакты | Первичная оценка |
| 5. Тестовое | Кандидат | Выдает и принимает тестовое по правилам вакансии | Тестовое сдано |
| 6. Ручной разбор | Специалист по подбору | Показывает карточку, риски, ответы, тестовое | Допуск к интервью |
| 7. Интервью со специалистом по подбору | Специалист по подбору | Хранит ссылку на запись или загруженный файл | Интервью проведено |
| 8. Расшифровка интервью | Платформа | Превращает запись в текст | Текст интервью сохранен |
| 9. Оценка интервью искусственным интеллектом | Платформа | Анализирует текст по критериям вакансии | Машинная оценка |
| 10. Оценка интервью специалистом | Специалист по подбору | Заполняет форму оценки независимо от ИИ | Человеческая оценка |
| 11. Решение о втором интервью | Платформа + специалист | Сводит две оценки | Допуск к руководителю |
| 12. Интервью с руководителем | Руководитель-заказчик | Хранит запись, расшифровку и форму оценки | Финальная оценка |
| 13. Итоговая оценка | Платформа | Сводит все этапы в единую карточку | Рекомендация |
| 14. Решение о предложении | Руководитель | Принимает личное финальное решение | Предложение / отказ / резерв |
| 15. Предложение работы | Руководитель + специалист | Собирает документ по шаблону с переменными | Предложение отправлено |
| 16. Принятие предложения | Специалист по подбору | Нажимает кнопку "Предложение принято" | Запуск адаптации |

## 3. Оценка после интервью со специалистом по подбору

После интервью должны быть две независимые оценки.

### Оценка искусственного интеллекта

Входные данные:

- расшифровка интервью;
- вакансия;
- грейд;
- критерии роли;
- ответы анкеты;
- тестовое задание;
- стоп-факторы.

Выход:

- краткое резюме интервью;
- оценка по критериям;
- сильные стороны;
- риски;
- противоречия с анкетой;
- вопросы для следующего интервью;
- рекомендация: допустить / ручной разбор / не допускать.

### Оценка специалиста по подбору

Специалист по подбору заполняет форму отдельно от оценки ИИ.

Поля формы:

- мотивация кандидата;
- релевантность опыта;
- коммуникация;
- адекватность ожиданий по деньгам;
- соответствие культуре компании;
- зрелость и ответственность;
- риски;
- общее впечатление;
- рекомендация по следующему этапу;
- комментарий для руководителя.

## 4. Оценка после интервью с руководителем

После интервью с руководителем повторяется тот же принцип:

- запись или ссылка на запись;
- расшифровка;
- анализ искусственным интеллектом;
- независимая форма оценки руководителя;
- итоговая рекомендация;
- финальное решение руководителя.

Руководитель не должен просто видеть одну итоговую цифру. Ему нужна сводка:

- где кандидат силен;
- где риск;
- что подтвердилось после двух интервью;
- что не совпадает между анкетой, тестовым и интервью;
- какие условия нужно зафиксировать в предложении работы.

## 5. Итоговая оценка кандидата

Итоговая оценка должна собираться из блоков:

| Блок | Вес по умолчанию |
| --- | --- |
| Первичная анкета | 20% |
| Тестовое задание | 25% |
| Интервью со специалистом по подбору | 20% |
| Интервью с руководителем | 25% |
| Стоп-факторы и риски | 10% |

Вес должен настраиваться под вакансию. Для продаж интервью может весить больше. Для монтажера или дизайнера тестовое может весить больше.

## 6. Предложение работы

Предложение работы собирается на платформе по шаблону.

Руководитель или специалист по подбору заполняет переменные:

- ФИО кандидата;
- вакансия;
- грейд;
- формат работы;
- дата выхода;
- испытательный срок;
- оклад;
- переменная часть;
- условия выплаты;
- график;
- руководитель;
- основные задачи на первые 30 дней;
- критерии успешного прохождения испытательного срока;
- срок действия предложения;
- контакт для ответа.

Платформа подставляет данные в стандартный текст и формирует готовое предложение.

## 7. Кнопка "Предложение принято"

В карточке кандидата появляется действие:

`Предложение принято`

Нажимает: специалист по подбору.

Что происходит:

- кандидат получает статус `Нанят`;
- вакансия получает отметку о закрытии или частичном закрытии;
- фиксируется дата принятия предложения;
- сохраняется финальная версия предложения;
- создается событие запуска адаптации.

Процесс адаптации не разрабатываем в этой версии. Только создаем точку входа для следующего этапа.

## 8. Риски

- Расшифровка может ошибаться, особенно при плохом звуке.
- ИИ может неверно трактовать интонации, паузы и контекст.
- Руководитель может переоценить личное впечатление и игнорировать данные воронки.
- Слишком длинная анкета до интервью снизит конверсию.
- Автоматический отказ без ручной проверки опасен для спорных кандидатов.
- Предложение работы является чувствительным документом, нужен контроль доступа и журнал изменений.

## 9. Минимальная рабочая версия

Для первой версии расширенной воронки достаточно:

1. Добавить этапы после тестового.
2. Добавить загрузку ссылки на запись интервью.
3. Добавить поле для расшифровки интервью.
4. Добавить форму оценки специалиста по подбору.
5. Добавить форму оценки руководителя.
6. Добавить итоговую сводку кандидата.
7. Добавить шаблон предложения работы.
8. Добавить кнопку "Предложение принято".

Автоматическую расшифровку и анализ ИИ можно подключить вторым шагом, если сначала нужно быстро проверить процесс вручную.
