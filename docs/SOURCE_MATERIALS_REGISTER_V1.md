# Реестр исходных материалов по подбору v1

## 1. Назначение

Этот документ фиксирует источники, из которых собираем систему подбора:

- организационная структура;
- список направлений и ролей;
- карточки должностей;
- анкеты кандидатов;
- тестовые задания;
- сценарии интервью;
- формы оценки;
- шаблоны предложения работы.

Задача реестра - не потерять старые документы и отделить рабочие источники от устаревших черновиков.

## 8. Первичные выводы из найденных материалов

1. У компании уже есть несколько вариантов оргструктуры, но они лежат в разных форматах: документы, таблицы, презентации, PDF.
2. По маркетингу материалов больше всего: есть роли, подчинение, показатели, грейды и примерные вилки.
3. По SMM уже есть почти полный пакет вакансии.
4. По менеджеру проекта есть публичное описание, но нужно достроить карточку роли, анкету, тестовое и оценку.
5. По специалисту по подбору есть анкеты, сценарии интервью и оценочная карта.
6. По предложению работы есть отдельная папка с примером.
7. По адаптации и онбордингу есть отдельная база, но ее лучше не включать в первую версию платформы подбора глубже точки запуска адаптации.
8. По компенсациям есть исторические материалы, которые можно использовать как черновики для грейдов и вилок, но их нужно согласовать отдельно.
9. Архив `Персонал 2021` полезен для восстановления ролей и процессов, но часть материалов может быть устаревшей.

## 9. Что нужно извлечь дальше

Из источников нужно собрать четыре рабочих справочника:

1. `Справочник направлений`.
2. `Справочник ролей и должностей`.
3. `Справочник грейдов`.
4. `Справочник шаблонов подбора`.
5. `Справочник компенсаций и условий`.
6. `Справочник адаптации`.

После этого по каждой роли можно создавать пакет вакансии:

- карточка роли;
- текст вакансии для HeadHunter;
- анкета;
- тестовое;
- структура интервью;
- форма оценки;
- критерии допуска на следующий этап;
- шаблон предложения работы.
