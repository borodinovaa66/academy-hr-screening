# Первый вход руководителя без вакансий

Карточка: HR-XFER-20260921-01. Issue: https://github.com/borodinovaa66/academy-hr-screening/issues/6

## Реализовано

- Владелец создаёт руководителя с пустым списком доступа.
- В форме есть явный пункт «Пока нет вакансий»: выбран при пустом доступе, очищает другие отметки; выбор конкретной вакансии снимает его. У существующей пустой учётной записи отображается та же подпись.
- Пустые кандидаты и аналитика возвращаются без ошибки авторизации.
- Кабинет показывает первый запуск; формы выбора собственных вакансий скрыты до появления первой.
- Поиск по названиям должностей возвращает только названия. Выбор заполняет название нового черновика, не копирует чужие материалы и не выдаёт доступ к чужой вакансии.
- Существующий конструктор создаёт отдельную позицию и назначает доступ создателю; можно создать свой запуск подбора.
- Убрана выдача корневой конфигурации чужой вакансии руководителю через GET /api/admin/config.
- HR_DATA_DIR позволяет выполнять проверки с отдельной временной базой.

## Проверки

- npm test: 15/15, включая HTTP-проверку создания пустого руководителя, входа, отдельной вакансии, запуска, изоляции второго руководителя и отказа в административных операциях; проверку переключения пункта «Пока нет вакансий» в дереве формы.
- node --check public/app.js; git diff --check.
- Локальный браузер: вход пустого руководителя, первый экран, поиск позиции, открытие конструктора с выбранным названием. Снимок экрана просмотрен.
- Проверки на синтетических данных, без обращения к HeadHunter и без production-изменений.

## Не завершено полное требование

Это исправление первого входа, а не полная реализация самостоятельной сборки всех материалов.
Существующий генератор наследует базовую анкету и сценарии; новые вопросы и тестовое требуют методической проверки. Руководитель ещё не может самостоятельно редактировать анкету: действуют права HR/владельца. Отдельная генерация двух адаптированных интервью и приёмка шести материалов относятся к HR-XFER-20260915-02 / Issue #2.

Полную задачу нельзя закрывать до проверки: руководитель создаёт и редактирует профиль, текст HH, анкету с оценкой, тестовое с критериями, два отдельных интервью; чужие данные недоступны; неподтверждённый комплект не публикуется.

Открытая саморегистрация не добавлена: владельцем по-прежнему выдаётся персональный доступ. Реальные сотрудники не создавались. Деплой, отправки и публикации требуют отдельного разрешения владельца.
