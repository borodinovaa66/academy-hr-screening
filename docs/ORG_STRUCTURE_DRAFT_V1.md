# Черновик финальной оргструктуры v1

## 1. Статус документа

Это рабочая версия после первого согласования с Андреем. Часть решений уже зафиксирована, оставшиеся спорные места вынесены отдельно.

Цель документа: собрать из разных материалов единую версию направлений, ролей, подчинения и спорных мест, чтобы после согласования перейти к пакетам вакансий.

## 2. Основные источники

Использованы источники из реестра:

- `Оргструктура для Миро АМ`;
- `Таблица распределения ответственностей с СОО`;
- `Структура маркетинга АМ`;
- `Направления деятельности и структура маркетинга АМ`;
- `Плейбук подбора и формирования команды`;
- `Методология подбора персонала общая`;
- `Функциональные обязанности`;
- `Описание вакансий`;
- локальные материалы по SMM и менеджеру проекта.

## 3. Управленческая логика

В текущей версии компания делится на 8 основных блоков:

1. Стратегия и управление.
2. Маркетинг и запуски.
3. Продажи.
4. Продукт, обучение и сопровождение.
5. Разработка, автоматизация и аналитика.
6. Операции и проектное управление.
7. Финансы, юридический блок и администрация.
8. Персонал, подбор, адаптация и культура.

Отдел разработки и автоматизации отвечает за автоматизацию бизнес-процессов, внедрение ИИ, корпоративную аналитику, BI, сбор данных и дашборды.

Техническая настройка воронок, LMS, вебинаров, платформ и отдельных технических задач запусков выполняется внешней компанией на аутсорсе.

## 4. Верхний уровень

| Роль | Зона ответственности | Подчинение / связь |
| --- | --- | --- |
| Собственник / генеральный директор | Стратегия, ключевые решения, финальная рамка по команде, критические наймы | Верхний уровень |
| Операционный директор | Действующая роль. Исполнение стратегии, ритм управления, межфункциональная координация, контроль блоков | Подчиняется собственнику |
| Руководитель маркетинга | Маркетинговая стратегия, лидогенерация, воронки, команда маркетинга. Руководитель маркетинга и руководитель отдела маркетинга - одна роль | Подчиняется операционному директору |
| Руководитель продаж | План продаж, воронка продаж, команда продаж, конверсии | Подчиняется операционному директору |
| Руководитель продукта / клиентского результата | Качество продукта, обучение, сопровождение, выполнение обещаний клиенту | Подчиняется операционному директору |
| Руководитель отдела разработки / менеджер проектов разработки | Автоматизация бизнес-процессов, ИИ-внедрения, корпоративная аналитика, BI, сбор данных, дашборды | Подчиняется операционному директору |
| Финансовый руководитель / финансовый менеджер | Бюджет, план-факт, платежи, финансовые риски | Подчиняется операционному директору, по ключевым вопросам - собственнику |
| Менеджер по персоналу | Подбор, оценка, адаптация, корпоративная культура, кадровые процессы, развитие функции персонала | Подчиняется операционному директору |
| Юрист | Договоры, юридические риски, рекламные материалы, претензии | Функционально работает с операционным директором и собственником |

## 5. Направления и роли

### 5.1. Стратегия и управление

| Роль | Для чего нужна | Подчинение |
| --- | --- | --- |
| Собственник / генеральный директор | Видение, стратегия, приоритеты, ключевые решения по людям и продуктам | Верхний уровень |
| Операционный директор | Превращает стратегию в систему управления, процессы, метрики и исполнение | Собственник |
| Помощник руководителя / бизнес-ассистент | Снимает операционную нагрузку, помогает с координацией, документами, встречами | Собственник или операционный директор |

Решение согласовано: операционный директор - действующая роль.

Спорное место: нужно уточнить, где проходит граница между менеджером проекта направления, продюсером и операционным директором.

| Инженер / разработчик / программист | Реализует автоматизации, интеграции, внутренние инструменты, сбор данных и дашборды | Менеджер проектов разработки |

Решение согласовано: аналитика становится общей функцией компании. Настройка воронок, LMS, вебинаров и платформ остается у внешней технической компании на аутсорсе.

| Роль | Для чего нужна | Подчинение |
| --- | --- | --- |

| Бухгалтер | Учет, отчетность, первичные документы | Финансовый руководитель |
| Казначей | Платежи, остатки, контроль движения денег | Финансовый руководитель |
| Юрист | Договоры, претензии, правовые риски, проверка рекламных материалов | Операционный директор / собственник |

Спорное место: нужно определить, финансовый руководитель - это отдельная управленческая роль или пока финансовый менеджер с расширенной ответственностью.

### 5.9. Персонал, подбор, адаптация и культура

| Роль | Для чего нужна | Подчинение |
| --- | --- | --- |
| Менеджер по персоналу | Весь функционал персонала: подбор, адаптация, корпоративная культура, кадровые процессы, развитие, коммуникация | Операционный директор |
| Рекрутер | Будущая роль внутри функции персонала: поиск и первичная коммуникация с кандидатами | Менеджер по персоналу |
| Специалист по адаптации | Будущая роль внутри функции персонала: запуск адаптации, чек-листы, контроль первых недель | Менеджер по персоналу |
| Директор по персоналу | Будущая управленческая роль при масштабировании компании | Собственник / операционный директор |

Решение согласовано: подбор - часть функционала менеджера по персоналу. В эту функцию входят все вопросы персонала, включая корпоративную культуру. Перспектива роста роли - директор по персоналу.

Граница текущего проекта: адаптацию пока не разворачиваем как полноценный процесс в платформе подбора. Фиксируем только точку запуска после статуса `Предложение принято`.

## 9. Что нужно согласовать с Андреем

### 9.1. По верхнему уровню

- Зафиксировано: операционный директор является действующей ролью и центром исполнения.
- Зафиксировано: отдельный коммерческий директор сейчас не нужен.
- Зафиксировано: маркетинг и продажи подчиняются операционному директору.
- Уточнить подчинение продукта, финансов, отдела разработки и функции персонала в финальной схеме.

### 9.2. По маркетингу

- Утвердить продуктовые направления: `Собственники`, `Наемные руководители`, `B2B`, `Курс для тренеров`.
- Решить, нужны ли отдельные продюсеры по каждому направлению.
- Решить, где заканчивается зона продюсера и начинается зона менеджера проекта.
- Зафиксировано: руководитель маркетинга и руководитель отдела маркетинга - одна роль.
- Зафиксировано: SMM работает матрично по всем направлениям, каналам и социальным сетям.

### 9.3. По продукту и сопровождению

- Утвердить владельца клиентского результата.
- Разделить методолога, руководителя программ, куратора и тьютора.
- Зафиксировано: комьюнити сейчас нет, это проектная роль на будущее.

### 9.4. По разработке, автоматизации и аналитике

- Зафиксировано: аналитика становится общей функцией компании.

### 9.5. По персоналу

- Зафиксировано: менеджер по персоналу отвечает не только за подбор, но и за адаптацию, корпоративную культуру и кадровые процессы.

## 10. Рекомендация

Для следующего шага не нужно пытаться сразу утвердить всю оргструктуру до последней роли.

Практичный путь:

1. Утвердить верхний уровень и 8 направлений.
2. Утвердить первую очередь ролей.
3. Создать пакеты вакансий для SMM, менеджера проекта и менеджера по персоналу.
4. На этих трех ролях проверить шаблон карточки, анкеты, тестового, интервью и оценки.
5. После этого масштабировать на продажи, продукт и финансы.
