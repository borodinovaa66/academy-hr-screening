# Справочники вакансий и грейдов v1

## 1. Что создаем

Нужно создать базовые справочники для платформы подбора бизнес-онлайн-школы:

- справочник направлений компании;
- справочник вакансий;
- справочник грейдов;
- справочник компетенций;
- справочник этапов воронки;
- справочник шаблонов вакансий для публикации;
- справочник тестовых заданий;
- справочник критериев оценки интервью;
- справочник стандартных предложений о работе.

Эти справочники должны стать основой для всех следующих вакансий, чтобы не собирать каждую воронку с нуля.

## 2. Справочник направлений компании

| Поле | Описание |
| --- | --- |
| Код направления | Короткое техническое имя |
| Название | Например: маркетинг, продажи, продукт, методология, кураторы, производство контента, операционный блок |
| Руководитель | Кто является заказчиком вакансий по направлению |
| Типовые роли | Какие позиции чаще всего нанимаются |
| Активность | Используется / архив |

Первые направления для бизнес-онлайн-школы:

- маркетинг;
- продажи;
- сопровождение клиентов;
- методология и продукт;
- производство контента;
- социальные сети и сообщества;
- операционное управление;
- аналитика;
- административная поддержка.

| Поле | Описание |

| Название вакансии | Публичное название |
| Внутреннее название | Как роль называется внутри компании |
| Направление | Ссылка на справочник направлений |
| Грейд | Ссылка на справочник грейдов |
| Руководитель-заказчик | Кто принимает финальное решение |
| Ответственный специалист по подбору | Кто ведет кандидатов |
| Формат работы | Удаленно / гибрид / офис |
| Занятость | Полная / частичная / проектная |
| Зарплатная вилка | Минимум, максимум, валюта, до или после налогов |
| Цель роли | Зачем эта позиция нужна бизнесу |
| Ключевой результат | Что человек должен улучшить или закрыть |

## 4. Справочник грейдов

Грейд - это уровень самостоятельности, ответственности и ожидаемой ценности сотрудника.

| Грейд | Смысл | Самостоятельность | Ответственность | Кому подходит |
| --- | --- | --- | --- | --- |
| Стажер | Учится и выполняет простые задачи | Низкая | За отдельные поручения | Новички без устойчивого опыта |
| Младший специалист | Делает типовые задачи по инструкции | Низкая-средняя | За качество выполнения | Исполнитель с базовым опытом |
| Специалист | Самостоятельно ведет свою зону | Средняя | За стабильный результат | Уверенный исполнитель |
| Старший специалист | Улучшает процесс, видит риски | Высокая | За направление или сложные задачи | Сильный практик |
| Ведущий специалист | Проектирует решения и обучает других | Высокая | За систему работы в зоне | Эксперт направления |
| Руководитель направления | Управляет людьми, планом и результатом | Очень высокая | За бизнес-показатели | Лидер функции |

## 5. Поля грейда

Каждый грейд должен иметь описание:

- уровень опыта;
- типовые задачи;
- уровень самостоятельности;
- ожидаемая скорость работы;
- уровень ответственности за результат;
- коммуникация с руководителем;
- способность работать с неопределенностью;
- требования к аналитике;
- требования к инициативе;
- типовые ошибки;
- минимальная зарплатная вилка;
- максимальная зарплатная вилка.

## 6. Как использовать грейды в подборе

Грейд влияет на:

- текст вакансии;
- зарплатную вилку;
- сложность анкеты;
- сложность тестового задания;
- критерии оценки интервью;
- ожидания руководителя;
- итоговую оценку кандидата.

Пример: SMM-специалист уровня "специалист" должен не только публиковать контент, но и понимать аналитику, гипотезы роста, путь пользователя и качество заявок. Младший специалист может быть сильным исполнителем, но не обязан самостоятельно строить стратегию.
