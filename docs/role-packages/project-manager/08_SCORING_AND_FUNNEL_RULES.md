# Правила оценки и воронка кандидата

## 1. Этапы воронки

| Этап | Ответственный | Решение |
| --- | --- | --- |
| Отклик / переход на платформу | Кандидат | Начал анкету |
| Входной опросник | Платформа | Сильный / спорный / резерв / отказ |
| Ручной разбор анкеты | Менеджер по персоналу | Давать тестовое / отказ / резерв |
| Тестовое задание | Кандидат | Сдано / не сдано |
| Оценка тестового | Менеджер по персоналу + руководитель при необходимости | Звать на интервью / отказ |
| Интервью с менеджером по персоналу | Менеджер по персоналу | Допуск к руководителю / отказ / резерв |
| Интервью с руководителем | ЛПР | Предложение / отказ / резерв |
| Предложение работы | Руководитель + менеджер по персоналу | Отправлено |
| Предложение принято | Менеджер по персоналу | Запуск адаптации |

## 2. Вес этапов

| Этап | Вес |
| --- | --- |
| Входной опросник | 20% |
| Тестовое задание | 30% |
| Интервью с менеджером по персоналу | 20% |
| Интервью с руководителем | 25% |
| Риски и стоп-факторы | 5% |

Для этой роли тестовое весит больше, чем анкета, потому что важно увидеть реальное проектное мышление.

## 3. Первичная оценка анкеты

| Баллы | Статус | Действие |
| --- | --- | --- |
| 75+ | Сильный | Давать тестовое или звать на короткое интервью |
| 55-74 | Спорный | Ручной разбор менеджером по персоналу |
| 40-54 | Резерв | Только если мало кандидатов или сильная мотивация |
| До 39 | Отказ | Не вести дальше |

## 4. Оценка тестового

| Баллы | Статус | Действие |
| --- | --- | --- |
| 85-100 | Сильное тестовое | Интервью с менеджером по персоналу, затем руководитель |
| 70-84 | Рабочий уровень | Интервью, проверить слабые места |
| 55-69 | Спорно | Смотреть только при сильном опыте |
| До 54 | Слабое | Отказ |

## 5. Ключевые компетенции для итоговой оценки

| Компетенция | Что значит |
| --- | --- |
| Системность | Умеет раскладывать проект на задачи, сроки и ответственных |
| Ответственность | Не прячется за формулировкой "это не моя зона", если проект рискует сорваться |
| Коммуникация | Умеет спокойно добиваться результата от разных людей |
| Внимательность | Проверяет детали до запуска, а не после ошибки |
| Самостоятельность | Двигает процесс без постоянного ручного управления |
| Работа с цифрами | Может вести таблицы, собрать показатели и сделать выводы |
| Понимание запусков | Понимает базовую логику вебинаров, воронок, писем, заявок и продаж |
| Управление рисками | Видит блокеры заранее и предлагает варианты |

## 6. Красные флаги

Критичные:

- не готов к полной занятости;
- не готов выполнить тестовое;
- нет базовой работы с таблицами;
- не может привести конкретный кейс;
- перекладывает ответственность на других;
- скрывает проблемы или сообщает о них поздно;
- не фиксирует договоренности письменно;
- конфликтный стиль коммуникации.

Умеренные:

- нет опыта в онлайн-школах;
- слабое понимание воронок;
- мало опыта с подрядчиками;
- завышенные ожидания по доходу без соответствующего опыта;
- привык работать только по очень подробным инструкциям.

## 7. Сильные сигналы

- кандидат показывает реальные таблицы, чек-листы, отчеты или доски задач;
- умеет рассказать кейс по структуре: цель -> ограничения -> действия -> результат -> выводы;
- сам говорит про риски, контрольные точки и проверку готовности;
- понимает связь маркетинга и продаж;
- умеет писать короткий статус руководителю;
- в тестовом есть сроки, ответственные, проверки и метрики;
- спокойно говорит о своих ошибках и выводах.

## 8. Рекомендуемое правило допуска к руководителю

Допускать к интервью с руководителем, если:

- анкета не ниже 55 баллов;
- тестовое не ниже 70 баллов;
- нет критичных стоп-факторов;
- менеджер по персоналу не видит серьезного риска по культуре и ответственности.

Исключение: кандидат с сильным опытом может попасть к руководителю при тестовом 60-69 баллов, если слабые места объяснимы и проверяемы.

## 9. Что должна показывать карточка кандидата на платформе

- источник кандидата;
- статус воронки;
- баллы анкеты;
- стоп-факторы;
- ответы на открытые вопросы;
- ссылка на резюме;
- ссылка на тестовое;
- оценка тестового;
- сценарий интервью с менеджером по персоналу;
- форма оценки менеджера по персоналу;
- сценарий интервью с руководителем;
- форма оценки руководителя;
- итоговая рекомендация;
- решение;
- заметки;
- история действий.
