# Пакет вакансии: менеджер проектов

## 1. Назначение пакета

Этот пакет нужен, чтобы срочно запустить воронку подбора менеджера проектов для Академии менеджмента.

Роль в рабочем сленге: `проджект`.

Нормальное название для публикаций: `Менеджер проектов в онлайн-школу / EdTech`.

## 3. Рекомендуемая воронка

1. Кандидат видит вакансию на HeadHunter или в Telegram.
2. Переходит по ссылке на нашу платформу.
3. Заполняет входной опросник.
4. Платформа считает первичную оценку.
5. Менеджер по персоналу вручную смотрит сильных и спорных кандидатов.
6. Сильным кандидатам выдается тестовое задание.
7. После тестового проводится интервью с менеджером по персоналу.
8. После интервью сильные кандидаты идут на интервью с руководителем.
9. Руководитель принимает финальное решение.
10. Платформа помогает собрать предложение работы.
11. После принятия предложения запускается адаптация.

## 4. Что можно запускать сразу

Для срочного запуска достаточно:

1. Утвердить текст вакансии для HeadHunter.
2. Утвердить текст Telegram-поста.
3. Загрузить на платформу вопросы из `04_PLATFORM_QUESTIONNAIRE.md`.
4. Загрузить сценарии интервью из `06_PERSONNEL_INTERVIEW_SCRIPT.md` и `07_DECISION_MAKER_INTERVIEW_SCRIPT.md`.
5. Использовать тестовое задание `Вариант 1` из `05_TEST_ASSIGNMENTS.md` как основное.

Важно: текущая версия платформы пока заточена под SMM-анкету. Чтобы дать отдельную ссылку на опросник менеджера проектов, нужно добавить поддержку второй вакансии или временно заменить текущую конфигурацию анкеты на конфигурацию менеджера проектов.

## 5. Что требует согласования

1. Зарплатная вилка.
2. Формат оформления: трудовой договор / гражданско-правовой договор / самозанятость / ИП.
3. Нужен ли опыт именно в онлайн-школах как обязательный критерий или как преимущество.
4. Кто ЛПР по вакансии.
5. Кто будет непосредственным руководителем: руководитель маркетинга, продюсер направления или операционный директор.
6. Какие реальные инструменты используются сейчас: GetCourse, Bitrix24, Trello, ClickUp, Notion, Google Sheets, другие.
